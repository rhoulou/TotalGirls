Chaturbate for CloudStream 3

Live cams (Girls / Guys / Trans) — bridge to the Chaturbate Stremio addon server.

https://rhoulou.github.io/cloudstream/repo.json

  1. Install CloudStream 3 from the official GitHub releases Android 7.0+ required

  2. Open CloudStream 3, go to Settings → Extensions → Add repository If prompted, allow installing from this source.

  3. Paste the repository URL and confirm. The Chaturbate providers (Girls / Guys / Trans) appear under Extensions.

Tip: make sure your Chaturbate addon server is deployed and the plugin is built as a .cs3 file before installing. See the README.
